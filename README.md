## Descripción

Iron Force Gym es una página web desarrollada para un gimnasio,
donde los usuarios pueden conocer los servicios, planes,
entrenadores y realizar una solicitud de inscripción.

## Tecnologías

- HTML
- CSS
- JavaScript

## Funcionalidades

- Navegación mediante menú.
- Visualización de planes del gimnasio.
- Información sobre entrenadores.
- Formulario de inscripción.
- Validación del formulario mediante JavaScript.
- Diseño adaptable a dispositivos móviles.
